# Portfolio series roadmap

The release queue alternates frameworks, product domains, and engineering skills. A project moves to Live only after the quality gate in `QUALITY_STANDARD.md` passes.

| Release | Project direction | Stack | Skills demonstrated |
|---|---|---|---|
| P-001 | Fleet intelligence control center | Next.js | Data visualization, responsive UI, session state, CSV export |
| P-002 | Collaborative issue triage workspace | MERN-ready | Kanban interactions, filtering, audit log, JSON persistence adapter |
| P-003 | Personal finance scenario planner | Next.js | Forecasting, charts, validation, accessible forms |
| P-004 | Healthcare appointment operations | MERN-ready | Scheduling, calendar logic, capacity analytics, role-based views |
| P-005 | AI product usage and cost console | Next.js | Usage metering UI, limits, exports, anomaly indicators |
| P-006 | Real-estate portfolio command center | MERN-ready | Search, comparison, geospatial layout, asset performance |
| P-007 | Developer API observability portal | Next.js | Logs, latency charts, incident workflows, command palette |
| P-008 | Restaurant multi-location operations | MERN-ready | Inventory, reservations, staffing, location comparisons |
| P-009 | Subscription revenue analytics | Next.js | Cohorts, MRR movement, retention, scenario controls |
| P-010 | Learning management workspace | MERN-ready | Course authoring, progress tracking, assessments, dashboards |
| P-011 | Travel itinerary collaboration tool | Next.js | Drag-and-drop planning, budgets, maps, responsive itinerary |
| P-012 | E-commerce merchandising studio | MERN-ready | Catalog workflows, variants, promotions, inventory simulation |
| P-013 | Cybersecurity posture dashboard | Next.js | Risk scoring, findings workflow, evidence tracking, reports |
| P-014 | Construction project control room | MERN-ready | Milestones, cost tracking, issue registers, document indexes |

The queue can be reordered to prevent similar products from appearing consecutively.
